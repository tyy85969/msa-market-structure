# ADR-0005: Visual Design

## Status

Accepted

## Context

MSA needs a consistent visual vocabulary while the research model evolves. The vocabulary must remain sparse and must not be confused with claims about a reference indicator.

## Decision

The provisional MSA visual design is:

- Yellow = Confirmed Primary Structure;
- Cyan / Blue = Higher-Timeframe Reference;
- Green Dashed = Candidate / Forming Structure;
- Short Lines = Local Micro Structure.

This is an independent MSA visual design. It is not an assertion about the true meaning of colors used by any reference indicator.

## Consequences

- Research screenshots and future displays can use a shared legend.
- Candidate and confirmed structure remain visibly different.
- Colors may be revised through a later ADR if accessibility or validation requires it.
- Dense debug labels do not belong on the primary chart.
