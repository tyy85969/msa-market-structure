# Experiment registry

Formal experiments use research/experiments/EXP-XXX/ and must remain reproducible from a recorded commit.

Each experiment directory contains:

- README.md with the research question and run instructions;
- configuration with explicit parameters;
- a run script or notebook;
- results generated from the declared dataset;
- a report with conclusion and limitations.

Initial experiment identifiers are reserved as follows:

- EXP-001: baseline multi-timeframe confirmed Swing study;
- EXP-002: incremental historical reaction support/resistance study;
- EXP-003: clustering and resonance ablation study.

These entries define future research slots only. Phase 0 does not implement or claim results for them.
